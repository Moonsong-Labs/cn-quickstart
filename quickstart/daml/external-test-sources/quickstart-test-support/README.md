# Direct renewal test support

The test setup, preapproval, wallet queries, and transfer context are adapted from
[Splice 0.10.2](https://github.com/canton-network/splice/tree/e214318836feb7cee420dee33e85c7a6abbc7c04/token-standard).
The registry and wallet code come from `splice-token-standard-v2-test`. The shared
disclosure helpers and Amulet configuration come from `splice-token-standard-v1-test`.
Scripts exercise the official Amulet 0.1.25 implementation through the V2 transfer factory.
